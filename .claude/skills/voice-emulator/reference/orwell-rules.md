# The six rules, worked out

From George Orwell, *Politics and the English Language* (1946). The rules are
short. The work is turning each one into a thing you can check.

## i. Never use a metaphor, simile or other figure of speech which you are used to seeing in print.

The test is not "is this a metaphor" but "have I seen this exact phrase in print
a hundred times." Fresh, plain description is fine. Worn-out figures are not.

- Cut: "a double-edged sword," "a perfect storm," "the tip of the iceberg,"
  "navigate the waters," "a safety net," "kick the can down the road," "moving
  the goalposts," "at the end of the day," "the bottom line," "level playing
  field," "low-hanging fruit," "think outside the box," "when it comes to."
- Cut similes: "like a," "as safe as houses," "as X as Y."
- Instead: say the literal thing. Not "an inherited IRA is a ticking clock" but
  "you have a deadline to empty an inherited IRA."

## ii. Never use a long word where a short one will do.

Keep a short list in your head and swap on sight:

| Long | Short |
|------|-------|
| utilize | use |
| purchase | buy |
| approximately | about |
| prior to | before |
| subsequent to | after |
| commence | start |
| terminate | end |
| sufficient | enough |
| additional | more |
| facilitate | help |
| demonstrate | show |
| numerous | many |
| require | need |
| obtain | get |
| assist | help |
| indicate | show |

Keep the long word only when it is a real term of art with no plain swap
(for example, "amortization" in a mortgage answer), and then explain it plainly.

## iii. If it is possible to cut a word out, always cut it out.

Filler adds nothing. Delete it:

- "in order to" → "to"
- "due to the fact that" / "owing to the fact that" → "because"
- "the fact that" → (rewrite the sentence)
- "it is important to note that" / "it should be noted that" → (just note it)
- "for the purpose of" → "to" / "for"
- "in the event that" → "if"
- "at this point in time" → "now"
- "a number of" → "some" / "several"
- "in terms of" → (rewrite)
- intensifiers that weaken: "very," "really," "quite," "basically,"
  "actually," "essentially," "in fact."

## iv. Never use the passive where you can use the active.

Name the actor. "The IRS taxes withdrawals as ordinary income," not
"withdrawals are taxed as ordinary income." Passive hides who does what, which
is the opposite of what a finance or law answer needs. Keep passive only when the
actor is unknown or truly beside the point.

## v. Never use a foreign phrase, a scientific word, or a jargon word if you can think of an everyday English equivalent.

- Foreign: "per se," "vis-à-vis," "de facto," "inter alia," "prima facie,"
  "ergo," "et al." Use the plain word.
- Jargon: "leverage" (use "use"), "synergy," "incentivize" (use "encourage"),
  "operationalize," "utilize," "paradigm," "circle back," "bandwidth."
- Real terms of art (Roth IRA, capital gains, probate, RMD) stay, but say them
  once and explain in plain words. Do not stack them.

## vi. Break any of these rules sooner than say anything outright barbarous.

The rules serve clarity. When a rule fights clarity, clarity wins. If the only
short word is wrong, use the right long word. If the active voice forces a clumsy
sentence, use the passive. Never write something ugly or false just to obey a
rule. This rule is why the auditor is a helper, not the final judge.
